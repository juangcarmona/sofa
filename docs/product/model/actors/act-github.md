## Purpose

Supply authorized project, issue, pull request, review, check, workflow, and delivery evidence.

## Goals

Make project work and engineering evidence available within the caller’s existing access.

## Responsibilities

Provide source identifiers, revision and run information, timestamps, and links; report access or availability failures.

## Boundaries

GitHub evidence describes repository activity. It does not establish production incidents, unrecorded decisions, or the completeness of missing data.
