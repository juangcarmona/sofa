## Definition

A small, independently executable piece of repository work with source identity, scope, acceptance criteria, priority, risk, dependencies, and a decision boundary.

## Distinguish From

A GitHub issue may contain several work units. A work unit is not an execution run or an authorization to modify a source.

## Usage

UC-SHAPE-WORK-UNIT prepares it; UC-EXECUTE-WORK-UNIT runs it; UC-SCHEDULE-WORK selects it.
