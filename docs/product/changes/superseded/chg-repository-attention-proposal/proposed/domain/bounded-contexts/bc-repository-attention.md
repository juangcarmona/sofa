## Responsibility

Identify evidenced conditions that deserve Juan’s attention across the selected repositories, and explain collection coverage.

## Language

Attention items describe actionable observations. Collection outcomes explain which repositories and evidence categories were inspected and when.

## Boundaries

Own observation and explanation only. Work execution, workflow adoption, product approval, merge authority, and delivery analytics are outside this context in the first slice. This language boundary does not prescribe a service or deployment.

## External Relationships

Read evidence from ACT-GITHUB and present it to ACT-JUAN. Preserve source links and distinguish source facts from SoFa’s classifications.
