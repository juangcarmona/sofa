## Definition

A project configured with a repository identity and default branch. Its backlog, engineering, workflow, policy, capacity, risk, and delivery metadata may be discovered from the configured sources.

## Distinguish From

A project is not a GitHub issue, a work unit, an execution run, or a worker process. The initial explicit configuration identifies one repository and its default branch; additional repository grouping remains discovered or later configured.

## Usage

Portfolio and Project Configuration defines its minimum identity and reconciles discovered metadata; Backlog and Triage, Scheduling, Execution, and Delivery use the resulting evidence and policies.
