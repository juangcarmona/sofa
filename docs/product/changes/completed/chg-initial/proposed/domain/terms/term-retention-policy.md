## Definition

A bounded rule for how long execution metadata, delivery evidence, operational records, and detailed telemetry remain available.

## Distinguish From

A retention policy is not a deletion command, a project priority, or a guarantee that unavailable evidence can be recovered.

## Usage

Portfolio and Project Configuration selects a project policy; when none is configured, the shared default applies. Runtime Operations reports retention pressure and maintenance limits.
