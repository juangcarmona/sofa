## Definition

A candidate problem, opportunity, or improvement captured in SoFa before it has become a GitHub issue.

## Distinguish From

An idea is not the authoritative backlog item, a GitHub issue, a work unit, or an authorization to execute work. An idea must be promoted to a GitHub issue before it enters the normal backlog flow.

## Usage

Backlog and Triage may capture and refine it; promotion creates or links the GitHub issue that becomes the source of truth.
