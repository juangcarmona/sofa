# 12. Glossary

**Approved design; implementation pending.** Juan accepted this architecture on 2026-10-19. Product intent is recorded in [CHG-INITIAL](../product/changes/completed/chg-initial/change.md).

| Term | Definition |
| --- | --- |
| Attention item | Product term owned by [TERM-ATTENTION-ITEM](../product/model/domain/terms/term-attention-item.md) |
| Snapshot | Immutable result of one collection, including findings, observation interval, and coverage outcomes |
| Evidence-source port | Attention-owned interface through which the application obtains normalized observations |
| AppHost | Aspire composition program that launches local resources |
| Coverage outcome | Collection result distinguishing inspected, incomplete, unavailable, and unconfigured evidence |
